# Living Logbook

A portable tutoring and learning-handover skill. Google Drive holds the learner's authoritative records; GitHub holds only the reusable operating procedure.

## Quick start

1. Read [SKILL.md](SKILL.md) or install it as a skill using the AI host's supported method.
2. Give the AI the URL of your own authorized Google Drive logbook folder privately.
3. Ask it to read the current handover and resume the pending lesson.
4. At the end of substantive learning, ask it to verify the journal and handover updates.

Example prompt:
> Read the Living Logbook skill. My authorized Google Drive folder is [provide privately]. Restore the current learning state, resume the pending question, and maintain the logbook according to the skill.

## Expected Drive layout

- 01 — Learning Roadmap
- 02 — Learner Profile & Teaching Method
- 03 — Learning Progress & Handover
- 04 — Career & Income Strategy
- Learning Journal/
- Work Folder/

The host must already have authorized access to Drive. The skill does not authenticate, sync, or schedule work by itself. Without access, provide an exported handover and save any pending updates manually. Never commit personal learning records, private URLs, employer data or credentials here.
